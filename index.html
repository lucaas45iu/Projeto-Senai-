1. CLICK

💥 Estourador de Balões

O evento click é disparado quando o botão principal do mouse é pressionado e solto sobre o elemento.

🎈
Pontos de Explosão: 0
balloon.addEventListener('click', (e) => { ... })
2. MOUSEOVER & MOUSEOUT

🐱 O Gatinho Mágico

mouseover dispara quando o ponteiro entra no elemento; mouseout dispara quando ele se afasta.

😴
Zzz... Passe o mouse aqui para me acordar!
Estado Atual: Dormindo
pet.addEventListener('mouseover', acordar);
pet.addEventListener('mouseout', dormir);
3. INPUT

🤖 Robô Transmissor

O evento input dispara imediatamente a cada caractere digitado, apagado ou colado no campo.

📡 🤖
Transmissão em Tempo Real:
Aguardando sinal...
Caracteres: 0 Palavras: 0
input.addEventListener('input', (e) => { texto.innerText = e.target.value })
4. CHANGE

🧪 Caldeirão Alquímico

O evento change dispara quando a alteração do valor é confirmada (ao selecionar opção ou ao perder o foco).

✨
⚗️
Escolha uma fórmula acima para preparar a poção!
select.addEventListener('change', misturarPocao);
5. KEYDOWN

🎹 Pista de Dança & Sintetizador

O evento keydown dispara assim que uma tecla do teclado físico é pressionada.

🕺
Tecla Detectada: Nenhuma tecla
Código (e.code): -

💡 Pressione qualquer tecla do seu teclado ou clique nas teclas acima!

window.addEventListener('keydown', (e) => { moverDancarino(e.key) })
6. DBLCLICK

🥚 O Ovo do Dragão Lendário

O evento dblclick só dispara quando ocorrem dois cliques rápidos e consecutivos no mesmo elemento.

🥚
🐉
🔥
Dê um DUPLO CLIQUE rápido no ovo para chocá-lo!
egg.addEventListener('dblclick', chocarDragao);
7. FOCUS & BLUR

🔦 O Guardião dos Holofotes

focus ocorre ao entrar no elemento (recebe atenção); blur ocorre ao sair (perde o foco).

🦉
Clique no campo secreto abaixo para acender os holofotes!
FOCUS: Inativo BLUR: Aguardando
input.addEventListener('focus', acenderHolofotes);
input.addEventListener('blur', apagarHolofotes);
8. SUBMIT

🚀 Centro de Lançamento Espacial

O evento submit ocorre ao enviar um formulário. Com e.preventDefault(), impedimos que a página recarregue e executamos nossa lógica personalizada!

🚀
🔥💨
> Sistema pronto. Preencha os dados e pressione SUBMIT.
form.addEventListener('submit', (e) => { e.preventDefault(); lancarFoguete(); });
